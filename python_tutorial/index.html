Python alapok - Oktatás

Változók és típusok

Pythonban a változók típusát nem kell előre megadni. Egyszerű értékadással hozhatunk létre változókat, például x = 5.

Ciklusok

Leggyakrabban for és while ciklusokat használunk. A for ciklus sorozatok bejárására alkalmas, míg a while ciklus addig fut, amíg a feltétel igaz.

Függvények

Függvényt a def kulcsszóval definiálunk. Például: def osszeg(a, b): return a + b.
